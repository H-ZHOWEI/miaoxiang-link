# 喵想联动（手机 App）

配套电脑软件「喵想奇记-家用」v1.3.0+ 的安卓 App。让电脑和手机双向通信：

- **电脑 → 手机**：电脑上任务开始/完成/失败/停止，手机弹通知；
- **手机 → 电脑**：在手机上点任务组，电脑收到指令后自动执行；也可远程「暂停 / 继续 / 停止」正在跑的任务（需电脑端 v1.7.0+）；
- **多台电脑**：把家里/公司等多台电脑都配对进来，App 里一键切换控制哪台；
- **自动签到（v1.4 新增）**：「④ 自动签到」里配置步骤，让手机自己模拟点击/长按/滑动翻页，可手机手动、电脑下发、每日定时三种触发（电脑端需 v1.8.0+）。模拟操作需在系统设置里开启无障碍权限。

两端通过云端信箱中转，家里外面都能用，不需要公网 IP 或同一 WiFi，用配对码隔离。

## 安装

下载 Release 里的 `MiaoXiangLink-v1.4-release.apk` 安装到手机，允许通知权限。App 内置自动更新，以后有新版本打开时会提示。自动签到功能还需在「④ 自动签到」页开启无障碍权限。

## 快速开始

1. 电脑端「喵想奇记」→ 顶栏「手机联动」→ 生成配对码 → 启用 → 保存；
2. 手机 App「③ 设备」→「＋ 添加新设备」→ 填设备名称和同一个配对码 → 顶部显示「电脑在线」即成功；
3. 之后任务完成会通知手机，点「① 远程执行」里的任务组可远程让电脑执行；同页的「暂停 / 继续 / 停止」按钮可遥控正在跑的任务；
4. 多台电脑：重复第 1-2 步逐台添加，在「③ 设备」页点卡片切换当前控制的电脑。

详见 [操作说明.md](操作说明.md)。

## 从源码构建

用 Android Studio 打开本项目（需要 Android SDK 34 + JDK 17+），Run 或执行：

```bash
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。签名 release 可在 `local.properties` 配置 `storeFile` / `storePassword` / `keyAlias` / `keyPassword`。

## 技术说明

纯 Kotlin + OkHttp，直连 WorkBuddy 云服务的 REST 数据面读写一张 `link_messages` 表。云端的网络配置内置在 `CloudApi.kt`。
